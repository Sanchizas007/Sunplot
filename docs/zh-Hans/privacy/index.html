隐私

Sunplot 没有账户，也没有统计。你的位置、地点和描过的天际线不会离开设备；它发送的只有一条购买记录和一个匿名的 Apple Ads 代码，详见下文。

留在设备上的内容

  • 位置。用于计算太阳的路径，因为答案随纬度变化。它在设备上读取，从不发送。
  • 相机。实时画面用于描出天际线。不录制、不保存、不发送任何照片或视频。
  • 运动。指南针告诉应用手机朝向，好让太阳轨迹与画面对齐。
  • 你的地点。保存的地点和描过的天际线存放在应用自己的空间里，就在设备上。

我们收集什么

不收集任何关于你的地点的信息，也不收集你如何使用应用的信息：没有账户、没有使用分析、没有崩溃报告、应用内没有广告。应用里唯一的第三方是 RevenueCat，它会收到下文所述的购买数据和广告活动数据。App Store 隐私标签恰好列出这两类数据——购买和广告数据——都不与你关联，也都不用于跟踪。

购买与 RevenueCat

解锁是通过 App Store 的一次性购买，是否拥有由你的设备决定：Sunplot 询问 Apple 这个 Apple 账户是否拥有解锁，并得到是或否的答复。为了了解发生了哪些购买，应用还会把你的购买告知 RevenueCat——一项处理应用内购买的服务。RevenueCat 会收到来自 Apple 的购买凭据和交易详情、它自己生成的匿名应用用户 ID，以及任何网络请求都会附带的技术数据，例如 IP 地址、设备型号、系统版本、语言和国家或地区。它绝不会收到你的位置、你的地点、你描过的天际线，也不会收到你录入的任何内容。我们无法据此得知你是谁，RevenueCat 也不会用这些数据在其他公司的应用或网站上跟踪你。RevenueCat 自己的政策（revenuecat.com/privacy）说明了它如何处理这些数据。我们永远看不到你的姓名、银行卡或地址。

Apple Ads 归因

无论你是否来自广告，应用都会向 Apple 请求一个归因代码——它不说明你是谁——并在每次安装时仅一次，连同匿名应用用户 ID 一起交给 RevenueCat。如果你是在 App Store 点按我们的广告（Apple Ads）后安装了 Sunplot，RevenueCat 会用这个代码向 Apple 询问该广告属于哪个广告活动、广告组和关键词，并与同一个 ID 一并保存，以便我们了解哪些广告带来了购买。如果你并非来自广告，Apple 不会返回任何广告活动。Sunplot 不读取你的广告标识符（IDFA），也不会弹出跟踪许可请求，因为没有任何内容会与其他公司的应用或网站的数据合并。上文提到的 RevenueCat 政策同样适用于这些数据。

儿童

Sunplot 不面向儿童，对任何年龄的任何人，也不收集任何能说明他是谁的内容。离开手机的只有上文所述的购买记录和广告代码。

删除数据

删除应用即可清除它保存在手机上的全部内容。存放在别处的只有 RevenueCat 那里的匿名购买记录；如果你希望将其删除，请写信到支持邮箱，我们会安排删除。

变更

如果本政策变更，页脚的日期也会随之变更。
