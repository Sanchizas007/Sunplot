この場所はどれだけ日が当たりますか

種の袋にも苗のラベルにも、直射日光の時間が書いてあります。ところが自分の庭やベランダ、屋根が実際に何時間もらえているかは、ほとんどの人が知りません。

Sunplot はそれを数字で答えます。太陽がどこにあるかではなく——それは簡単な半分です——塀やガレージ、隣の木が取り分を持っていったあとでこの場所にどれだけ届くか、です。

カメラを稜線に向け、屋根や木のてっぺんを指でなぞってください。Sunplot は一日を1分ずつたどり、通り抜けてきた光だけを数えます。

分かること

  • 今日の直射日光の時間。苗のラベルと同じ区分（終日陽・半日陽・半日陰・日陰）で示します。
  • 日が差し始める時刻と消える時刻、そして一日がどう途切れるか。
  • 一年全体。終日陽が始まる時期と終わる時期、まったく日の入らない週。

しないこと

  • アカウントなし。登録するものはありません。
  • サーバーなし。すべて端末で計算し、電波がなくても動きます。
  • サブスクなし。一度の支払いで一年の画面とウィジェットがずっと使えます。
