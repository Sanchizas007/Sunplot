這塊地曬得到多少太陽？

每個種子袋和植物標籤都寫著直射陽光的時數。可是自家院子、陽台或屋頂究竟曬得到幾小時，幾乎沒人說得清。

Sunplot 用一個數字回答。不是太陽在哪裡——那是容易的一半——而是圍牆、車庫和鄰居家的樹各自拿走一份之後，還有多少落在這塊地上。

把相機對準天際線，用手指沿著屋頂和樹梢劃過去。Sunplot 把一天一分鐘一分鐘走一遍，只數穿過來的光。

它告訴你什麼

  • 今天的直射陽光時數，依植物標籤的說法分級：全日照、半日照、半陰、全陰。
  • 太陽何時照到、何時離開，以及一天被切成幾段。
  • 全年情況：全日照何時開始、何時結束，哪幾週完全沒有。

它不做什麼

  • 沒有帳號，不需要註冊。
  • 沒有伺服器，一切在手機上計算，沒有網路也能用。
  • 沒有訂閱。一次付費永久解鎖全年檢視和小工具。
